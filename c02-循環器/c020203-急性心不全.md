## 病態
- [[c020204-慢性心不全]]からの急性転化
- [[c029999-急性冠症候群]]や致死的な[[c029999-★不整脈]]

---
## 症状
- 背景の病態による
- [[c000000-sym-呼吸困難]]
- [[c020201-左心不全]]⇒[[c000000-phy-四肢の冷感]]、[[c010000-sym-傾眠]]、[[c080101-低ナトリウム血症]]
- [[c020202-右心不全]]⇒[[c020000-sym-浮腫]]、[[c019999-★腹水]]、[[c000000-phy-経静脈怒張]]
---
## 検査
- バイタルで[[c180100-★ショック]]の有無を確認
- 身体診察ではwet, dry所見をチェックする

- [[c020000-test-心エコー]]、[[c040000-img-胸部レントゲン]]
	- 心室拡大や左室駆出率低下、心臓の器質的病変の検索

- Swan Gantzカテーテルによる血行動態の測定
- カテーテルの負担が大きい場合は、Norrhia Stevenson分類：主訴と診察所見による分類。心係数の代わりに低灌流所見（[[c020000-vit-小脈]]など）。肺動脈楔入圧の代わりにうっ血所見

|           | 肺動脈楔入圧 < 18       | 肺動脈楔入圧 > 18           |
| --------- | ----------------- | --------------------- |
| 心係数 > 2.2 | type I            | type II<br>肺うっ血       |
| 心係数 < 2.2 | type III<br>心拍出量↓ | type IV<br>肺うっ血＋心拍出量↓ |

---
## 治療
- type II⇒後負荷を下げるため、[[c020000-tre-★血管拡張薬]]、[[c080000-tre-◆利尿薬]]
- type III⇒心拍出量を上げるため、[[c080000-tre-初期輸液]]、[[c070000-base-ドーパミン]]などカテコラミン
- type IV⇒[[c020000-tre-IABP]]、==[[c070000-base-ドーパミン]]==

- 肺うっ血（[[c049999-肺水腫]]）：血管拡張薬と利尿薬の使い分け
	- 右：体液過剰⇒肺だけではなく、全身[[c020000-sym-浮腫]]
		- この場合は[[c080000-tre-◆利尿薬]]で溢水の解除
	- 左：末梢血管収縮⇒後負荷↑⇒上流にうっ血が回る⇒肺うっ血
		- この場合は[[c020000-tre-★血管拡張薬]]で後負荷の解除
